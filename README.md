# Dart Assignments

This repository contains Dart programming lab exercises covering nested loops, conditional logic, terminal input handling, and basic algorithms.

---

## 📁 Repository Structure

* `lap1.dart` - **Lab 1: Print Patterns**
  Generates geometric shapes and nested loop patterns (triangles, hollow squares, letter shapes, and side-by-side extra credit grid layouts).
  
* `lap2.dart` - **Lab 2: Electricity Bill Calculator**
  Calculates a customer's electricity bill based on units consumed, applying unit rates, a 15% surcharge for bills over 500,000 Riel, and a minimum bill threshold of 1,000 Riel.

* `lap3.dart` - **Lab 3: Currency Converter**
  An interactive menu-driven program that allows users to input custom exchange rates and convert Khmer Riel (KHR) into USD, EUR, and Yuan.

* `lap4.dart` - **Lab 4: Student Grade Calculator**
  Takes subject marks as input, calculates total marks and percentage, and assigns grades (`A`, `B`, `C`, `D`, `Fail`) based on specific evaluation criteria.
